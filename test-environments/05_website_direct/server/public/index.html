Single payment — x402 v2 (ETH — testnet)

        
The official x402 protocol: MetaMask signs an EIP-3009 authorisation (no transaction and no gas for the payer); the server verifies the payment itself, settles it itself in ETH on Ethereum Sepolia (testnet — the settlement is synthetic/mock) and pays the gas.

A single on-chain top-up opens a session with credit, a budget and a validity period; after that every reading is paid for with an EIP-191 signature, without a new transaction.

Session and identity

      
On the first visit the server stores a short-lived sid token in a cookie
        (HttpOnly) and later reads it only to correlate events of the same session
        (402 → proof → access). Identity is the wallet and one-time tokens, not the IP address,
        so the flow survives a network change (wifi ↔ mobile internet, NAT). A missing or changed
        sid never causes a rejection.
